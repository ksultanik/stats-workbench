# Statistics Workbench

A single-page statistics calculator with a live distribution plot that redraws as you change inputs.

## Tools

- **Distributions:** normal curve areas and inverse, z-scores and percentiles, binomial and Poisson (with normal approximation), p-values and critical values for z, t, χ² and F
- **Describe:** descriptive statistics with histogram, fitted normal curve and box plot
- **Infer:** confidence intervals, z and t hypothesis tests, chi-square tests, one-way ANOVA
- **Relationships:** correlation and linear regression with prediction intervals
- **Plan:** sample size and power analysis

## Running it

No build step and no dependencies. Open `index.html` in a browser, or serve it with GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder).

All math runs in the browser (incomplete gamma and beta functions for the t, χ² and F distributions).
